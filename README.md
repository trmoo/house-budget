# 🏠 내 집 예산 계산기

내 조건으로 **얼마짜리 집을 살 수 있는지**, 그리고 **통장에 현금이 얼마나 있어야 하는지**를
2026년 10월 규정으로 셈해 주는 계산기입니다.

주소: https://trmoo.github.io/house-budget/ (비밀번호가 있습니다)

## 쓰는 법

1. **① 내 상황** — 종잣돈, 소득, 이미 있는 빚을 적습니다.
   빚은 「내가 실제로 내는 돈」이 아니라 **규정이 셈하는 방식**으로 넣습니다(마이너스통장은 한도 전액).
2. **② 집·지역** — 집값·시세·면적과 **지역(규제 / 수도권 비규제 / 지방)**, 주택 수, 생애최초 여부를 고릅니다.
3. **③ 결과** — 시중은행·디딤돌·보금자리론 세 갈래를 나란히 놓고, 무엇이 한도를 묶었는지,
   현금이 얼마 필요한지, 지금 종잣돈으로는 최대 얼마짜리까지 되는지를 보여 줍니다.
4. **④ 근거** — 쓴 규정값과 출처, 그리고 **이 앱이 모르는 것**을 적어 두었습니다.

## 무엇이 다른가

- **지역을 세 갈래로 가릅니다.** 「비규제」 한 칸으로 뭉치면 틀립니다 — 지방은 스트레스 금리가 0.75%p 이고
  상한·만기 제한이 없는데, 수도권 비규제는 3.0%p 에 6·4·2억 상한과 30년 만기 제한을 함께 받습니다.
- **마이너스통장은 한도 전액을 5년에 나눠** DSR 에 넣습니다(월 이자만 넣는 계산기와 한도가 1억 넘게 차이 납니다).
- **한도가 큰 쪽이 아니라 매달 갚는 돈이 적은 쪽**을 권합니다(디딤돌 3.8% ↔ 보금자리론 5.4%).
- **무엇이 한도를 묶었는지**와 그것을 푸는 방법을 말해 줍니다.
- 등기 비용에 「등록면허세」 같은 없는 항목을 넣지 않습니다. 국민주택채권 할인율도 **지금 값(약 15.8%)** 을 씁니다.
- 확실하지 않은 값은 **「불확실」이라고 화면에 밝힙니다.**

## 만들고 고치기

```bash
npm install
npm start          # 개발 서버
npm test           # 계산 시험 (규정값·세금 구간·표시)
npm run build      # dist/index.html 한 파일
```

`npm run build` 결과인 `dist/index.html` 은 인터넷 없이 더블클릭으로 열립니다.

## 주의

이 계산기는 **공개된 규정으로 셈한 추정**입니다. 은행의 심사 결과가 아니고 대출·세무 상담을 대신할 수 없습니다.
규정은 자주 바뀌니 계약 전에는 은행과 구청에서 다시 확인하세요.
적어 넣은 금액·소득은 서버로 가지 않고 그 브라우저에만 남습니다.
